# PPT 默认样式与验收规范

本指南仅包含跨主题通用的排版与验收要求。

## 内容与排版

- 每页围绕明确的主题组织内容，标题、正文、图注和参考文献保持清晰的层级。
- 使用 16:9 页面、统一页边距和协调留白，文字与图片不得超出页面或相互遮挡。
- 图片等比例放置，坐标轴、刻度和图例保持完整可读；示意图与数据图明确区分。
- 数据图应可追溯到原始数据或生成脚本，相关输入随项目保留。

## 字体、字号与颜色

- 默认中文使用 Microsoft YaHei，英文、数字和公式使用 Arial。
- 正文、卡片正文、重要图注和图表标签默认不小于 18 pt。页眉、页脚、参考文献、页码和公式上下标可采用角色化的较小字号。
- 默认主色为深灰；主色、辅助色、对比色和警告色在同一报告中保持一致的语义。

## 验收

- 生成后运行 `scrinium document inspect <file>`，检查页面结构和越界。
- 环境允许时，使用报告本地的预览方式逐页检查文字、重叠、留白、裁切和换行。
- 按报告目的复核页面顺序、信息密度、事实准确性和结论依据。
- 用户手工编辑的 PPTX 与生成脚本需要同步维护；重新生成前先合入人工修改。
